介面總覽

雪雪劇本工坊採用三欄式佈局，讓編劇能在同一個畫面中同時處理劇本內容、專案資料與格式預覽。

頂部工具列

最上方的工具列由左至右依序為：

  • 劇本工坊 Logo：點擊無動作，僅作為識別標誌
  • 專案選單：切換目前編輯的劇本專案，旁邊的 ＋ 可新增專案
  • 六種段落格式按鈕：場景標題、動作描述、角色名稱、對白、語氣說明、轉場——游標所在行的格式會亮起對應按鈕
  • 匯出區（右側）：Fountain、Word、備份 App、列印 PDF
  • ◀ ▶ 按鈕：收合或展開左右側欄，讓編輯區最大化

左側資料欄（五個頁籤）

  • 場景：自動列出劇本中所有場景標題，點擊可跳轉
  • 分場卡：獨立管理每個場景的詳細資訊，可拖曳排序
  • 角色：建立與管理角色資料卡
  • 筆記：自由記錄靈感、橋段、研究資料
  • 資料：上傳圖片、PDF、Word 等參考文件

中央編輯區

劇本的主要書寫區域。頂端輸入劇本標題與副標題，下方逐行輸入劇本內容。每一行左側顯示行號與可點擊的格式標籤。

右側面板（三個頁籤）

  • 預覽：即時模擬正式劇本排版，白底黑字 Courier 字型
  • 統計：場景數、字數、對白行數、角色台詞次數排行
  • 格式說明：Fountain 標記對照表與相容軟體列表

建立新專案

點擊頂部工具列中專案選單旁的 ＋ 按鈕，輸入劇本名稱，即可建立全新的空白專案。每個專案擁有獨立的劇本、分場卡、角色、筆記與參考資料。

輸入劇本標題

編輯區最上方有兩個輸入欄：

  • 第一行輸入劇本標題（大字置中，列印時也會顯示）
  • 第二行輸入副標題、作者名、版次等資訊（選填）

六種段落格式

每一行劇本都屬於六種格式之一，對應好萊塢劇本的標準結構。格式決定了這行文字在劇本中的外觀、縮排與語義。

場景標題
標示新場景的開始。包含地點、室內外、時間。
INT. 城市街道 - 黃昏
動作描述
描述畫面中發生的事、人物行為、場景氛圍。

（輕聲、轉向窗外）

如何切換格式

有三種方式可以切換目前行的段落格式，任選一種：

  1. 點擊頂部工具列按鈕：直接點「場景標題」「動作描述」等按鈕，游標所在行立即套用
  2. 點擊行首格式標籤：每行左側都有一個帶顏色的小按鈕，點擊後展開下拉選單，選擇目標格式
  3. 鍵盤快捷鍵：按 Tab 循環到下一種格式，按 Shift+Tab 反向切換

Enter 智慧換行邏輯

按下 Enter 時，系統會根據目前行的格式自動判斷下一行的格式，減少重複操作：

目前格式按 Enter 後
場景標題→ 動作描述
動作描述→ 動作描述（繼續）
角色名稱→ 對白
對白→ 角色名稱（自動準備下一個角色）
語氣說明→ 對白
轉場→ 場景標題

場景標題工具列

當游標停在一行場景標題時，該行前方會自動出現兩組快速切換按鈕，讓你不用手動輸入 INT. 或 - 夜：

室內 / 室外切換（INT / EXT）

  • INT：室內景（Interior）
  • EXT：室外景（Exterior）
  • INT/EXT：室內外切換景

點擊後，系統自動在行首補上或替換對應的英文縮寫，不影響後面的地點文字。

時間切換（日 / 夜 / 黃昏 / 清晨）

點擊四個時間按鈕之一，系統自動在地點後加上「- 日」「- 夜」等標準格式的時間後綴。

⌨️
Alt + T 快捷鍵 在場景標題行按下 Alt+T，可以快速循環切換四個時間選項（日→夜→黃昏→清晨→日），不必移開手離開鍵盤。

這兩組按鈕也會在你手動輸入 INT.、EXT.、- 夜 等文字時自動同步高亮，反映目前狀態。

分場卡系統

分場卡是整個專案系統的核心。每張分場卡代表劇本中的一個場景，可以在劇本成形之前就先獨立規劃，也可以在寫作過程中隨時補建。

建立分場卡

切換到左側「分場卡」頁籤，點擊右上角的 ＋ 按鈕，填寫以下欄位：

  • 場次編號：系統自動編號，可手動修改
  • 場景標題：這場戲的簡短描述
  • 地點：場景發生的地方
  • 時間：日、夜、黃昏、清晨
  • 室內 / 室外：INT、EXT、INT/EXT
  • 出場角色：用逗號分隔多個角色名稱
  • 場景功能：這場戲推進了什麼故事
  • 衝突：場景中的核心張力或衝突
  • 備註：任何補充說明

導入劇本

分場卡建立後，點擊卡片上的 ⬇ 導入劇本 按鈕，系統會自動在劇本中插入：

  • 標準格式的場景標題行（如 INT. 咖啡館 - 夜）
  • 一行空白動作描述，供你直接開始填寫
  • 若有角色，自動加入第一個角色名稱與空白對白行

導入後，分場卡與劇本場景之間建立連結，卡片上會顯示「已導入劇本」標記。修改分場卡不會自動改動劇本，修改劇本也不會覆寫分場卡，兩者保持獨立。

拖曳排序

在左側分場卡列表中，將滑鼠移到任意一張卡片上，游標會變成抓取手形。按住滑鼠左鍵直接拖動即可調整順序。拖動時會看到橘色指示線顯示放置位置。要移到最後一張卡片後面，拖到列表底部的空白虛線區放手即可。

依分場卡順序重排劇本

拖曳重新排序分場卡後，若想讓劇本的場景順序也同步更新，點擊分場卡列表底部出現的 ↕ 依分場卡順序重排劇本 按鈕。系統會將所有已連結的場景群組（包含其後的動作、對白等段落）依照分場卡的新順序重新排列。

⚠️
重排前請先確認 重排劇本是一個較大的操作，系統會跳出確認視窗說明影響範圍。重排後無法自動撤銷，建議先用「⬇ 備份 App」儲存一個備份版本。

右鍵選單

在分場卡上按右鍵（或長按）可快速選擇：導入劇本、編輯、刪除。

角色資料庫

切換到左側「角色」頁籤，可以為每個主要角色建立獨立的資料卡。

建立角色卡

點擊右上角 ＋ 按鈕，填寫角色資料：

  • 姓名：角色全名，會自動抓取首字作為頭像縮寫
  • 年齡：年齡或年齡範圍
  • 身分 / 職業：角色的社會身份
  • 性格特質：核心性格描述
  • 角色弧線：這個角色在故事中的成長或轉變
  • 備註：其他補充說明

右側「統計」頁籤中也會自動統計每個角色的台詞出現次數，方便檢視各角色的戲份分佈。

創作筆記

切換到左側「筆記」頁籤，可以記錄任何與劇本相關的靈感、研究資料或創作備忘。

每則筆記有標題與內容兩個欄位，支援自由文字輸入。點擊任一筆記卡片可開啟編輯，也可以在編輯視窗中刪除該筆記。

📌
使用建議 筆記適合用來放：故事主題與核心問題、參考影片或書籍摘要、橋段靈感、角色背景故事、對白草稿、修改紀錄等。

參考資料上傳

切換到左側「資料」頁籤，可以上傳任何與劇本創作相關的參考文件。

支援的檔案格式

  • 圖片：JPG、PNG、GIF、WEBP 等（角色參考圖、場景 moodboard、服裝道具參考）
  • PDF：論文、劇本參考、資料手冊
  • Word 文件：.doc、.docx
  • 試算表：.xlsx、.csv
  • 簡報：.pptx
  • 網頁：.html、.htm
  • 純文字：.txt、.md（Markdown）

上傳方式

  • 拖曳上傳：直接從桌面或 Finder 把檔案拖進「資料」頁籤的虛線放置區
  • 點擊上傳：點擊放置區，或點右上角 ＋ 按鈕，選擇檔案

圖片檔案會顯示縮圖預覽，其他格式顯示對應 icon 與檔案大小。點擊任一檔案可在新分頁開啟預覽，右側 ✕ 可移除。

ℹ️
注意：參考資料儲存於瀏覽器記憶體 上傳的參考資料存在目前瀏覽器的工作記憶體中，關閉或重新整理頁面後會清除。如需永久保存，請在關閉前點「⬇ 備份 App」下載整個 HTML 檔案，但請注意大型檔案可能使備份檔案大幅增加。

右側預覽與統計

即時預覽

右側「預覽」頁籤以白底黑字、Courier 等寬字型模擬正式劇本頁面，每次輸入後約 0.3 秒自動更新，讓你隨時確認排版效果。劇本標題也會同步顯示在預覽頂部。

劇本統計

「統計」頁籤顯示：

  • 場景數、總行數、總字數、對白行數
  • 角色台詞次數排行（依對白行數統計）
  • 預估頁數（以每頁 50 行估算）

格式說明

「格式說明」頁籤提供 Fountain 標記對照表，以及與本編輯器匯出格式相容的第三方劇本軟體列表，供未來換用專業工具時參考。

匯出與備份

工具列右側提供四種匯出方式，各有不同用途：

⬇ Fountain（.fountain）

匯出符合 Fountain 1.1 國際標準的純文字格式，可直接匯入以下專業劇本軟體，格式零失真還原：

  • Highland 2（Mac）
  • WriterDuet（網頁版）
  • Slugline、Logline、FadeIn
  • Final Draft（透過轉換工具）

⬇ Word（.docx）

匯出符合好萊塢標準的 Word 文件，格式規格如下：

  • 紙張：US Letter（8.5 × 11 吋）
  • 字型：Courier New 12pt
  • 左邊距 1.5 吋、右 / 上 / 下邊距各 1 吋
  • 角色名縮排至頁面 3.7 吋處
  • 對白左縮排 0.5 吋、右縮排 1.5 吋
ℹ️
Word 匯出需要網路連線 Word 匯出功能使用 docx.js 函式庫（從 CDN 載入，約 500KB），按下按鈕時需要網路連線。按鈕顯示「⏳ 生成中…」表示正在處理，完成後自動下載。

⬇ 備份 App（.html）

將整個劇本工坊應用程式連同目前所有資料（專案、劇本內容、分場卡、角色、筆記）一起打包成單一 HTML 檔案下載。這是最重要的備份方式——建議每次重要修改後都下載一份。備份檔案可直接用瀏覽器打開，完全離線可用。

🖨 列印 / 匯出 PDF

呼叫瀏覽器的列印對話框。在對話框中選擇「另存 PDF」即可匯出 PDF 檔案，格式採用好萊塢標準頁邊距（左 1.5 吋、右 1 吋）。列印時左側欄、右側欄、工具列等介面元素全部隱藏，只輸出劇本正文。

常見問題

Q：資料會自動儲存嗎？

目前版本的資料存在瀏覽器的工作記憶體中，關閉或重新整理頁面後資料會消失。請養成定期點擊「⬇ 備份 App」下載 HTML 備份檔的習慣，每次工作結束都下載一份是最安全的做法。

Q：備份的 HTML 檔如何繼續編輯？

用瀏覽器（建議 Chrome 或 Safari）直接打開備份的 .html 檔即可，所有功能完整保留，完全離線可用。

Q：為什麼 Word 匯出按鈕沒反應？

Word 匯出需要網路連線以載入函式庫。請確認網路連線正常，然後重新整理頁面再試。若仍有問題，可改用「列印 PDF」作為替代。

Q：可以在手機上使用嗎？

可以開啟，但本編輯器主要為桌機設計，在小螢幕上三欄佈局會比較擁擠。建議在 iPad 或電腦上使用以獲得最佳體驗。

Q：Fountain 格式是什麼？可以貼到 Word 嗎？

Fountain 是一種以純文字書寫劇本的開放標準格式，副檔名為 .fountain，可用任何文字編輯器開啟。若要貼入 Word，直接開啟 .fountain 檔複製內容即可，但格式需要手動重排。建議直接使用本編輯器的 Word 匯出功能以保留完整格式。

Q：分場卡與劇本的連結是什麼意思？

當你從分場卡「導入劇本」後，這張分場卡的 ID 會記錄在對應的場景標題行中，場景標題行也會回記分場卡的 ID。這個雙向連結讓「依分場卡順序重排劇本」功能得以正確找到並移動對應的場景群組。連結是單純的資料標記，不會讓兩者的文字內容互相影響。

Q：可以同時管理多個劇本專案嗎？

可以。點擊頂部工具列的 ＋ 按鈕可新增劇本專案，透過左側的專案下拉選單切換。每個專案的劇本、分場卡、角色、筆記完全獨立。備份時，所有專案的資料都會一起打包進備份 HTML 檔中。
