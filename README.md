# ✨ 小葉劇本工坊 Pro

**Snow Script Studio Pro**

一款專為**繁體中文創作者**設計的網頁版劇本編輯器，結合好萊塢劇本格式、自動排版與創作輔助工具，讓編劇能專注於故事本身，而不是格式。

---

## 🎬 專案簡介

小葉劇本工坊是一個以「編劇工作流程」為核心設計的工具，
支援從**靈感發想到正式劇本輸出**的完整創作過程。

不同於一般文字編輯器，本工具強調：

* 劇本格式自動化
* 創作流程整合
* 繁體中文友善設計

---

## 🚀 核心功能

### ✍️ 劇本編輯系統

* 好萊塢標準劇本格式（Scene / Action / Dialogue / Parenthetical）
* Tab / Shift+Tab 快速切換格式
* Enter 自動延續正確格式
* 支援快捷鍵操作（提升寫作速度）

---

### 🎭 分場卡與創作輔助

* 分場卡（Scene Cards）管理劇情結構
* 角色、筆記、資料區整合
* 劇本與分場卡互相導入

---

### 📥 劇本匯入（重點功能）

* 支援 Word `.docx` 匯入
* 支援貼上純文字自動解析
* 可手動修正辨識結果
* 快速轉換為劇本格式

---

### 📤 匯出與備份

* 匯出 PDF（可列印）
* 匯出 Word 文件
* 匯出 Fountain 格式
* JSON 備份 / 還原

---

### 📚 使用指南系統

* 內建「使用指南」彈窗
* 快速上手操作教學
* 降低學習門檻

---

## 🧠 設計理念

本工具的設計核心是：

> **讓創作者不用思考格式，只需要專注在故事。**

設計重點包含：

* 符合編劇實際 workflow
* 降低技術門檻
* 提供直覺操作體驗
* 支援繁體中文排版習慣

---

## 🛠 技術架構

* 單頁應用（Single HTML）
* 前端框架：React
* UI：Tailwind CSS
* 本地儲存：LocalStorage

---

## 🧪 開發背景

本專案起源於創作者在實際編劇過程中的痛點：

* Word 排版不穩定
* 劇本格式調整耗時
* 缺乏整合式創作工具

透過 AI 協作開發（Claude），逐步完成：

* 劇本格式系統
* 匯入 / 匯出功能
* 編劇工作流程整合

## 💡 使用方式

1. 開啟編輯器
2. 新建劇本或匯入既有稿件
3. 使用 Tab 快速切換格式
4. 完成後匯出 PDF / Word

---

## ⚠️ 注意事項

* 資料目前儲存在瀏覽器（LocalStorage）
* 建議定期匯出 JSON 備份
* 不同瀏覽器列印效果可能略有差異
